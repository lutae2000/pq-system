== Authentication

Frontend login uses a single active session per `loginId`.

The login response includes `token.accessToken` and `token.expiresAt`. Store that access token on the client and send it as `Authorization: Bearer <accessToken>` when calling authenticated user APIs.

This login session is separate from the service-to-service JWT token issued by `POST /token`.
`/token` requires service authentication headers and returns `accessToken` for backend integration calls.

Session check:

`GET /auth/session`

Signup:

`POST /auth/signup`

Request body:

```json
{
  "employeeNo": "250001",
  "userName": "Seongtae Lee",
  "loginId": "stleekm",
  "userPassword": "password",
  "deptCode": "10",
  "groupCode": "100"
}
```

Login requests still use the request body below.
